# DoğruTemin

Doğrudan temin süreçlerinin hazırlanması, firma tekliflerinin karşılaştırılması, belge üretimi, arşiv ve veri güvenliği için .NET 8 / WPF masaüstü uygulaması.

## 4.2.0 RC1

Bu dal/paket; DoğruFatura finalinde kullanılan görsel kalite, yazı keskinliği, DPI/resize, erişilebilirlik, veri güvenliği, merkezi sürümleme, otomatik test ve Windows Setup kalite yaklaşımını DoğruTemin'e taşır.

Önemli kullanıcı düzeltmesi: özel tarih alanlarında seçili tarih artık alan içindeki **×** düğmesiyle veya **Delete / Backspace** tuşlarıyla temizlenebilir.

Final Setup, RC1 kullanıcı testi tamamlanmadan üretilmez.
