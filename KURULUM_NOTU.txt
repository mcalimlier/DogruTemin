DOGRUTEMIN 4.3.0 - KURULUM NOTU
=====================================

DoğruTemin Windows 10/11 x64 için self-contained hazırlanır. Hedef bilgisayarda .NET SDK, .NET Runtime, Visual Studio veya Excel gerekmez.

KULLANICI VERISI
- Yeni veri kökü Masaüstü\DoğruTemin klasörüdür.
- 4.1.x sürümlerindeki Belgeler\DoğruTemin verileri ilk açılışta güvenli biçimde KOPYALANIR.
- Kaynak eski veri silinmez; hedefte aynı dosya varsa üzerine yazılmaz.
- Güncelleme ve kaldırma işlemleri Masaüstü\DoğruTemin içindeki veri, yedek, log ve PDF dosyalarını silmez.

KOD IMZASI VE SMARTSCREEN
- 4.3.0 sürümü yayın kararıyla Authenticode sertifikası olmadan dağıtılmaktadır.
- Windows SmartScreen bazı bilgisayarlarda "Bilinmeyen yayıncı" uyarısı gösterebilir.
- Kurulum dosyasını yalnız doğrulanmış GitHub Release kaynağından alın ve SHA-256 değeriyle doğrulayın.
- Bu imzasız dağıtım kararı 4.3.0 sürümüne özeldir; sonraki sürümlerde imza politikası yeniden uygulanır.

DOGRULAMA
- Setup üretiminden önce Release build ve otomatik testler çalışır.
- GitHub Actions ayrıca temiz kurulum, güncelleme, kullanıcı verisi koruma ve kaldırma smoke testlerini yürütür.
